#　問題

Relationsの深さ `← 1/3 →` については、階層を深くしたあとで、`←ボタン`を押して階層を浅くして、別のレコードを選択しても、直接隣り合っているRelationsパネルしか更新されない。
選択している行でRelationsが異なることがあるため、浅くした後で別のレコードを選択したら、階層はリセットされるべきである。

# 再現手順

shopテーブルを開く
右ペインのshop_productミニテーブルの0,0をCtrl+左クリック
←ボタンをクリック
shopテーブルの0,1をクリック
→ボタンをクリック

# 期待する動作

shopテーブルの0,1をクリックした時点で、← 1/3 → が ← 1/2 → になる
