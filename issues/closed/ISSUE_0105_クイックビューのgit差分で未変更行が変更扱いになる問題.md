# ISSUE_0105 クイックビューのgit差分で未変更行が変更扱いになる問題

## 概要

クイックビューのgit差分表示において、変更していない行のセルまで変更されたと誤認識される。

## 再現手順

1. chara テーブルを開く
2. id=1 の行の `recover_stamina` に `100` を代入する
3. 保存する（Ctrl+S）
4. クイックビューでgit差分を確認する

## 期待される動作

- id=1 の `recover_stamina` セルのみが変更として表示される

## 実際の動作

- id=1 だけでなく、id=2 や id=3 の行も `recover_stamina` が変更されていると認識・表示される
- id=2, id=3 の行は一切編集していない

## 補足

git diff の出力では id=1 の行のみが変更されている（正しい）：

```diff
-1,,,,,,1,
+1,100,,,,,1,
 2,,,,,,1,
 3,,,,,,2,
```

クイックビュー側の差分比較ロジックが、行単位ではなく列単位で比較する際に、未変更行のセルまで変更扱いにしている可能性がある。
