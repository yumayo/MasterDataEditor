# ISSUE_0131 フリーズペインの表示不具合を修正する（背景透過・行ヘッダー消失）

## 概要

行・列の固定（フリーズペイン、ISSUE_0119）に2つの表示不具合がある:

1. **背景透過**: `position: sticky` で固定されたセルの背景が透過しており、スクロール時に下層のセルが透けて見える
2. **行ヘッダー消失**: 行を固定した際、固定行の行ヘッダー（行番号セル）が `position: sticky` ではなく `position: relative` のままになっており、縦スクロール時に行ヘッダーだけがスクロールアウトして消える。これにより固定行の行番号が見えなくなり、右クリックで「行の固定を解除」にアクセスできなくなるため、一度固定した行を解除することが事実上不可能になる

## 背景

### 背景透過の問題
`position: sticky` で固定されたセルはスクロール時に他のセルの上に重なるが、背景色が未設定（`transparent`）のままだと下のセルの内容が透けて見え、テキストが重なり合って判読不能になる。

### 行ヘッダー消失の問題
DOMダンプ（`.CONTEXT/dump/freeze-pane/行を固定するとstickyスタイルが適用される.html`）で確認した結果:

- **固定行のデータセル**: `position: sticky; top: 21px; z-index: var(--z-index-freeze-row);` — 正しくstickyが適用されている
- **固定行の行ヘッダー**: `position: relative; left: 0px; z-index: 20; top: 21px;` — `position: relative` のままで、縦スクロール時に固定されない

行ヘッダーにも `position: sticky` と適切な `top` 値を設定する必要がある。

## 要件

### 不具合1: 固定セルへの背景色設定

- 固定行・固定列のセル（`<td>`, `<th>`）に不透明な背景色を設定する
- 背景色は通常セルと同じ色（テーマに応じた色）を明示的に指定する
  - 通常行: 通常の背景色（白系）
  - 偶数行/奇数行のストライプがある場合: それぞれの行に対応する色を設定する
  - 選択中のセル: 選択色が背景色より優先される
  - ホバー行: ホバー色が背景色より優先される
- 固定行 × 固定列が交差する左上角のセルも同様に背景色を設定する
- 背景色はCSS変数（`--cell-bg` 等、既存の変数があればそれを使用）で管理し、テーマ変更に追従できるようにする

### 不具合2: 固定行の行ヘッダーにstickyを適用する

- 行を固定した際、固定行の行ヘッダー（`.editor-table-row-header`）にも `position: sticky` と適切な `top` 値を設定する
- 行ヘッダーは元々 `position: sticky; left: 0px` で横スクロール時に固定されているため、行固定時には `top` も追加して縦横両方向に固定する
- z-indexは固定行 × 固定列の交差セル（左上角）と同等にする（行ヘッダーは常に最左端の固定列と同じ扱い）

## 期待される動作

### 背景透過の修正
1. `id`, `name` 列を固定する
2. 横スクロールする
3. 固定列のセルが不透明な背景で表示され、下のセルが透けて見えない
4. 行を固定して縦スクロールした場合も同様に透けない

### 行ヘッダー消失の修正
1. 1行目を「この行まで固定」で固定する
2. 縦スクロールする
3. 固定行のデータセルと行ヘッダー（行番号）がともに画面上部に固定される
4. 固定行の行ヘッダーを右クリックして「行の固定を解除」を選択できる

## 対象ファイル（変更）

- `WebView/src/editor-table.css` — 固定セルへの `background-color` 設定
- `WebView/src/editor-table-render.ts` — 固定行の行ヘッダーに `position: sticky` + `top` を設定するロジック修正
- `WebView/e2e/freeze-pane.spec.ts` — 固定行の行ヘッダーがstickyであることのテスト追加
