# ISSUE_0126 行ドラッグ移動と行複数選択の操作を分離する

## 概要

行ヘッダーのドラッグ操作が「行の移動」と「行の複数選択」で競合している問題を解消する。選択済みの行のみドラッグ移動可能とし、未選択の行をクリックし続ける操作で複数選択を行えるようにする。

## 背景

ISSUE_0122 で行のドラッグ移動を追加したが、行ヘッダーのドラッグ操作が行の複数選択と衝突している。現状では行ヘッダーをドラッグすると常にドラッグ移動モードに入ってしまい、「複数の行を選択したい」という操作ができない。行の移動と複数選択は操作の起点（選択済み行 vs 未選択行）で明確に区別する必要がある。

## 要件

### ドラッグ移動の開始条件を変更する

- **選択済みの行ヘッダー** をドラッグした場合のみ、行ドラッグ移動モードに入る
- **未選択の行ヘッダー** をドラッグした場合は、行ドラッグ移動を開始しない（複数選択として扱う）
- 判定タイミング: `mousedown` 時点で対象行が選択範囲内かどうかを確認する

### 行の複数選択操作

- 未選択の行ヘッダーを `mousedown` → そのままドラッグ（マウスを押したまま他の行ヘッダー上を通過）すると、通過した行が選択に追加される
- `mouseup` で選択が確定する
- Ctrl や Shift の修飾キーなしで、直感的にドラッグによる連続選択ができる

### 操作の判定フロー

```
行ヘッダーで mousedown
  ├─ 対象行が選択済み → 5px以上移動でドラッグ移動開始（従来動作）
  │                     → 5px未満で mouseup → クリック（行選択の切替）
  └─ 対象行が未選択   → 対象行を選択に追加
                        → ドラッグ（mousemove）で通過した行も選択に追加
                        → mouseup で選択確定
```

### 視覚フィードバック

- 選択済み行のヘッダーにはカーソルを `grab` にする（ドラッグ移動可能であることを示す）
- 未選択行のヘッダーにはカーソルを `default` または `pointer` にする（クリック選択であることを示す）
- ドラッグ選択中は、通過した行がリアルタイムで選択ハイライトされる

### 既存動作との整合性

- Shift+クリックによる範囲選択は従来通り維持する
- Ctrl+クリックによる個別トグル選択は従来通り維持する
- 列ヘッダーのドラッグ移動には影響しない（列は従来通りの動作）

## 期待される動作

### 未選択行からのドラッグ → 複数選択

1. どの行も選択していない状態で、3行目の行ヘッダーを `mousedown` する
2. 3行目が選択される
3. マウスを押したまま5行目まで移動する
4. 3〜5行目が選択状態になる
5. `mouseup` で選択が確定する

### 選択済み行からのドラッグ → 行移動

1. 3〜5行目が選択されている状態で、4行目（選択済み）の行ヘッダーを `mousedown` する
2. 5px以上移動すると行ドラッグ移動モードに入る
3. 8行目の位置にドロップすると、3〜5行目がまとめて8行目の位置に移動する

### 選択済み行のクリック解除

1. 3〜5行目が選択されている状態で、4行目の行ヘッダーをクリック（`mousedown` → 移動なし → `mouseup`）する
2. 4行目のみが選択された状態になる（範囲選択が解除される）
