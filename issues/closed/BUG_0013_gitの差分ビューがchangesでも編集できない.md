#　問題

gitの差分はchangesのみ変更可能です。
データの入力もセルをダブルクリックしないと入力が始まらないです。
想定では、右ペインのミニテーブル上でセルを選択状態であれば、いきなり入力可能な認識です。

ダブルクリックして、現れるテキストフィールドにもう一回クリックすることで入力が可能になります。
なぜかデータを入力するのに2工程も必要です。

# 再現手順

quest_rewardテーブルを開く
1行目1列目を5に変更する
Ctrl+Sで保存

gitのアイコンをクリック
quest_rewardテーブルをソースコントロールから開く
右ペインの4行目を右クリック
下に行を挿入
5行目の1列目をクリック
キー入力してもテキストフィールドが表示されない

# 期待する動作

キー入力したらテキストフィールドが表示される
