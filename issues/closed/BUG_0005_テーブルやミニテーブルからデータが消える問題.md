#　問題

ミニテーブル上でデータ行を追加したり削除したりすると、テーブル上のデータが破損する
CSVに保存するときはデータは正常です。
ミニテーブルとテーブル間のデータの持ち方が根本的に間違ってそう。

これは単純な不具合課題に思えますが、大分難航しそうです。

そのため、シンプルなアプローチを提案しますので、これを議論して実装してください。

# シンプルなアプローチ

ミニテーブルといえど、データをテーブルと分けるのではなく、通常のテーブルと全く同じDOMをもち、あくまでも外部キーでフィルターをかけているだけという設計にしてください。
そうすることで、行の追加や削除も、通常のテーブルと同様、データが破損したりおかしくなったりすることはなくなります。

# 再現手順

questテーブルを開く
右ペインのquest_rewardミニテーブルの2行目を右クリックし、下に行を追加する
そこには、5,1,1,1 を入力する
エクスプローラーからquest_rewardテーブルを開く
タブからクエストマスターをクリック
先程追加した右ペインのquest_rewardミニテーブルの3行目を右クリックし、行を削除する
タブからクエスト報酬マスターをクリック

テーブルは以下が表示される

3,3,2,1 キャラ,2 ひつじ
4,4,3,2 アイテム,5 尖ったかま
4,4,3,2 アイテム,5 尖ったかま
