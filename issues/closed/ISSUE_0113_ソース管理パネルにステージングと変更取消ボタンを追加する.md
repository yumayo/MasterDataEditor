# ISSUE_0113 ソース管理パネルにステージングと変更取消ボタンを追加する

## 概要

SOURCE CONTROL パネルの changes / staged セクションに、ファイル操作用のSVGアイコンボタンを追加する。

## 要件

### changes セクション
- **+ボタン（SVG）**: ファイルを staged に移動する（git add 相当）
- **戻る矢印ボタン（SVG）**: 変更を取り消す（git checkout 相当）

### staged セクション
- **-ボタン（SVG）**: ファイルを changes に戻す（git reset 相当）
- **戻る矢印ボタン（SVG）**: 変更を取り消す（git checkout 相当）

## 期待される動作

- changes の各ファイル行に「+」「戻る矢印」ボタンが表示される
- staged の各ファイル行に「-」「戻る矢印」ボタンが表示される
- 「+」クリックで該当ファイルが staged に移動する
- 「-」クリックで該当ファイルが changes に戻る
- 「戻る矢印」クリックで該当ファイルの変更が破棄される
