# ISSUE_0127 FK列のint値を右揃えにしヒント句を値の左側に表示する

## 概要

FK参照列の数値（int型）セルが左揃えで表示されている問題を修正し、通常のint列と同様に右揃えにする。加えて、参照ヒント句が数値の右側に表示されて見づらい問題を解消し、ヒント句を数値の左側に表示するよう変更する。

## 背景

ISSUE_0118 で数値列（int / float / double）を右揃え表示にしたが、FK参照列は型に関わらず従来の左揃えのままになっている。FK列の実データはint型の主キー値であることが多く、他のint列と揃えて右揃えにすべきである。

また、現在の参照ヒント句（例: FK値 `3` に対する表示名 "ポーション"）はセル内でFK値の右側に表示されている。右揃えの数値と右側のヒント句が隣接すると「数値+テキスト」が密着して可読性が低下する。ヒント句を数値の左側に配置すれば、「ヒント句（左）→ 数値（右揃え）」というレイアウトになり、数値列としての右揃えの一貫性を保ちつつ参照先の情報も自然に読み取れる。

## 要件

### FK列のint値を右揃えにする

- FK参照列であっても、参照元の列型がint / float / double の場合は右揃えで表示する
- 参照元の列型がstringの場合は従来通り左揃えを維持する
- 型判定はスキーマ定義から取得する

### ヒント句の表示位置を左側に変更する

- セル内のレイアウトを「ヒント句（左寄せ） ── FK値（右寄せ）」に変更する
- ヒント句は薄い色（現状通り）で表示し、FK値と視覚的に区別する
- ヒント句が長い場合は省略（`text-overflow: ellipsis`）し、FK値の表示領域を侵食しない
- ヒント句とFK値の間には適切な余白を設ける

### セル内レイアウト（変更後）

```
変更前: | 3  ポーション            |  ← 左揃え、値の右にヒント句
変更後: | ポーション            3  |  ← ヒント句が左、値が右揃え
```

### 影響範囲の限定

- 通常テーブルとミニテーブル（RelationsPanel内）の両方に適用する
- 編集モード時（GridDropdownInput表示中）のレイアウトには影響しない
- ヒント句が存在しないFK列（参照先テーブルに表示列がない場合）は単純な右揃え表示のみ

## 期待される動作

1. `shop_product` テーブルの `item_id` 列（FK、int型）を確認する
2. セルに `3` と表示され、右揃えになっている
3. ヒント句 "ポーション" は `3` の左側に薄い色で表示されている
4. 通常のint列（例: `price`）と数値の揃え位置が一致している
5. ヒント句が長い場合（例: "超レアドラゴンスレイヤーソード"）は省略されて `3` の表示を圧迫しない

## 対象ファイル（変更）

- `WebView/src/editor-table.css` — FK列の右揃えスタイル、ヒント句左配置のレイアウト（flexbox等）
