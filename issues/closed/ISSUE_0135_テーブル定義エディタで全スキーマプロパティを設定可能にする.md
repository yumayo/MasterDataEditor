# ISSUE_0135 テーブル定義エディタで全スキーマプロパティを設定可能にする

## 概要

テーブル定義エディタ（新規作成・編集）で、現在は列名・型・主キーしか設定できない。
schema.json が持つすべてのプロパティをUIから設定できるようにする。

## 現状

### 設定できる項目
| レベル | プロパティ | UI |
|--------|-----------|-----|
| テーブル | `name` | テキスト入力 |
| テーブル | `description` | テキスト入力 |
| 列 | `name` | テキスト入力 |
| 列 | `type` | ドロップダウン |
| 列 | `primary_key` | チェックボックス |

### 設定できない項目
| レベル | プロパティ | 説明 |
|--------|-----------|------|
| 列 | `comment` | 列の説明文 |
| 列 | `reference` | 外部キー参照（単純参照 `"table.column"` または動的参照オブジェクト） |
| 列 | `width` | 表示幅（px） |
| 列 | `default` | デフォルト値 |
| 列 | `renderAsHtml` | HTML描画フラグ（`<br>`タグ等） |
| テーブル | `reverseReferencePriority` | 逆参照優先度 |

## 要件

### 列レベル
- **comment**: テキスト入力フィールドを追加
- **reference**: 参照設定UI（単純参照 `table.column` のテキスト入力、または動的参照のオブジェクト設定）
- **width**: 数値入力フィールドを追加
- **default**: テキスト入力フィールドを追加（型に応じた入力）
- **renderAsHtml**: チェックボックスを追加

### テーブルレベル
- **reverseReferencePriority**: 数値入力フィールドを追加

## 対象ファイル

- `WebView/src/table-definition-editor.ts`

## 備考

- 編集モードでは `originalSchema` により既存値が引き継がれているが、UIで変更できないため実質的に固定値となっている
- 特に `comment` と `reference` はマスターデータ編集において重要な情報であり、UIから設定できないのは不便
