# ISSUE_0119 行/列の固定（フリーズペイン）を追加する

## 概要

Excelの「ウィンドウ枠の固定」に相当する機能を追加する。ユーザーが指定した位置で行・列を固定し、残りの領域だけがスクロールするようにする。現状は列ヘッダー行（1行目）と行ヘッダー列（行番号列）のみ `position: sticky` で固定されているが、データ行・データ列の任意の位置での固定には対応していない。

## 背景

マスターデータのテーブルはカラム数が多く（20〜50列）、横スクロールすると `id` や `name` といった識別列が画面外に消えてしまう。Excelでは「ウィンドウ枠の固定」で先頭数列を固定できるが、本ツールにはこの機能がない。特にゲームプランナーが大量のパラメータ列を持つテーブル（敵ステータス、スキルパラメータ等）を編集する際に、どの行を編集しているか見失う原因になっている。

## 要件

### 列の固定

- 先頭N列を固定し、横スクロール時にも画面左端に留まるようにする
- 固定列と非固定列の境界に視覚的な区切り線（太線または影）を表示する
- 固定列数は列ヘッダーの右クリックコンテキストメニューから設定する:
  - 「この列まで固定」: クリックした列までを固定する
  - 「列の固定を解除」: 固定を解除する
- 固定列は `position: sticky` + 動的な `left` 値で実装する（各固定列の left を前列の幅の累計に設定）
- 行ヘッダー列（行番号）は常に最左端に固定される（既存動作を維持）

### 行の固定

- 先頭N行を固定し、縦スクロール時にも画面上端に留まるようにする
- 固定行と非固定行の境界に視覚的な区切り線を表示する
- 固定行数は行ヘッダーの右クリックコンテキストメニューから設定する:
  - 「この行まで固定」: クリックした行までを固定する
  - 「行の固定を解除」: 固定を解除する
- 固定行は `position: sticky` + 動的な `top` 値で実装する（各固定行の top をヘッダー行高さ＋前行の高さの累計に設定）
- 列ヘッダー行は常に最上端に固定される（既存動作を維持）

### z-index の管理

- 固定領域が交差する左上の角（固定行 × 固定列）は最も高い z-index を持つ
- 固定行のみ、固定列のみ、通常セルの順に z-index を設定する
- 既存の z-index 設計（`z-index.css`）と整合させる

### 固定状態の永続化

- テーブルごとの固定列数・固定行数を localStorage に保存する
- タブを閉じて再度開いた際に固定状態が復元される

### 固定領域の視覚的表現

- 固定列の右端に 2px の影（`box-shadow` または擬似要素）を表示する
- 固定行の下端に 2px の影を表示する
- 固定領域の背景色は通常セルと同一だが、影によって境界が明確になる

### 制約事項

- フィルハンドルのドラッグ操作は固定領域をまたいでも正しく動作すること
- セル選択の範囲選択は固定領域をまたいでも正しく動作すること
- 列幅変更は固定列に対しても通常通り動作すること（変更後に後続固定列の left を再計算）
- ソート・フィルター操作は固定行の並び順にも正しく反映されること
- ミニテーブル（RelationsPanel内）では固定機能を無効にする

## 期待される動作

1. `name` 列のヘッダーを右クリックし「この列まで固定」を選択する
2. `id` 列と `name` 列が固定され、横スクロールしても画面左端に留まる
3. 固定列の右端に影が表示され、固定領域と非固定領域の境界がわかる
4. 再度右クリックして「列の固定を解除」を選択すると、固定が解除される
5. 行についても同様に、行ヘッダーの右クリックから固定・解除ができる
6. タブを閉じて再度開くと、固定状態が復元されている
