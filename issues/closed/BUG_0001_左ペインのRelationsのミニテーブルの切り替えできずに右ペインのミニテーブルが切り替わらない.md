#　問題
Relationsパネルが左側にある時、ミニテーブルを選択しても選択セル自体はそのミニテーブル内で変わらないため、右側のRelationsが切り替わらないです。

# 説明
左ペインのRelationsパネルのミニテーブルが1行のみの場合、左ペインのミニテーブル間を行き来しても、右側のRelationsが切り替わらないです。
ミニテーブル内に複数行があれば、行選択で右ペインのRelationsのミニテーブルは切り替わります。
ただ、左ペインのミニテーブル内のセル選択をすでにしていると、左ペインのミニテーブルを切り替えても、右ペインのミニテーブルは変わらないです。

# 再現手順

skillテーブルを開く
右ペインのcharaミニテーブルの0,0のセルをCtrl+左クリック
左ペインのcharaミニテーブルの0,0のセルを左クリック
左ペインのskill_nameミニテーブルの0,0のセルを左クリック
もう一度左ペインのcharaミニテーブルの0,0のセルを左クリック

# 期待する動作
右ペインではskill、chara_name、quest_rewardミニテーブルが表示される
