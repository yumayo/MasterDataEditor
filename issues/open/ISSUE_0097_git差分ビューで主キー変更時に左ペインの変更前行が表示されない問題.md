# 問題

git差分ビューで主キーを変更したCSVを比較すると、左ペイン（変更前）に変更前の主キー行が表示されない。
主キーベースで差分マッチングしているため、変更前にしか存在しない主キーの行が左ペインから消えてしまっている可能性がある。

例: 主キーを `1,2,3` → `1,2,4` に変更した場合
- 左ペイン: id=1, id=2 のみ表示（id=3 が消えている）
- 右ペイン: id=1, id=2, id=4 が正常に表示されている

# 期待する動作

- 左ペインに変更前の全行（id=1, id=2, id=3）が表示されること
- id=3 の行は削除された行として赤くハイライトされること
- 右ペインに id=4 の行が追加された行として緑でハイライトされること

# 備考

ISSUE_0096（日本語列の文字化け）と関連する可能性がある。差分マッチングのロジックが主キーベースで行われているなら、主キーが変わった行は「削除+追加」として扱うべき。
