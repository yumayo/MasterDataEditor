# ISSUE_0125 セルブックマーク機能を追加する

## 概要

特定のセルをブックマークし、後から即座にジャンプできる機能を追加する。ブックマークはファイルに即時永続化され、アプリケーション再起動後も保持される。ブックマークされたセルには視覚的なマーク（黄色〜オレンジ）を右上に表示する。

## 背景

大規模なマスターデータを編集する際、頻繁に参照・編集するセルが散在していることが多い。現状では目的のセルに到達するために毎回テーブルを開いてスクロールする必要がある。ブックマーク機能があれば、作業中のセルに印を付けておき、ワンアクションで戻ることができる。コマンドパレット（ISSUE_0124）がテーブル単位・クエリ式単位のジャンプを提供するのに対し、ブックマークは「このセルに後で戻る」という個人的なマーキングを提供する。

## 要件

### ブックマークの保存内容

ブックマーク1件につき以下を保存する:

- `tableName`: テーブル名（例: `item`）
- `rowKey`: 行を特定する主キー値（例: `3`）
- `columnName`: 列名（例: `name`）
- `label`: 表示用ラベル（ブックマーク時のセル値をスナップショットとして保存、候補リストでの識別用）
- `createdAt`: 作成日時（ISO 8601形式）

### 永続化

- ブックマークの追加・削除のたびに即座にファイルへ保存する（遅延書き込みしない）
- 保存先: `bookmarks.json`（データディレクトリ直下）
- 形式: JSON配列
- C#バックエンドの `IHostApi` に保存・読み込みAPIを追加する
- アプリケーション起動時にブックマークファイルを読み込む

### ブックマークの追加

- 対象セルを右クリック → コンテキストメニューに「ブックマークに追加」を表示する
- キーボードショートカット: `Ctrl+D`（選択中のセルをブックマーク）
- 同一セル（テーブル名 + 主キー値 + 列名が一致）を重複登録しない
- 追加直後にファイルへ永続化する

### ブックマークの削除

- ブックマーク済みセルを右クリック → コンテキストメニューに「ブックマークを削除」を表示する
- `Ctrl+D` でトグル動作（ブックマーク済みなら削除）
- サイドバーのブックマーク一覧から個別削除
- 削除直後にファイルへ永続化する

### ブックマークへのジャンプ

- サイドバーに BOOKMARKS パネルを追加する（EXPLORER / REFERENCES / SEARCH と並列）
- ブックマーク一覧をクリックすると、該当テーブルを開き、保存された `columnName` の列かつ `rowKey` の行のセルにジャンプする
- テーブルが未オープンの場合は自動的にタブを開いてからジャンプする
- コマンドパレット（Ctrl+P）からもブックマーク一覧にアクセスできるようにする（`@bookmark` プレフィクス等）

### セルの視覚的マーク

- ブックマークされたセルの右上隅に小さな三角形マーク（▲）を表示する
- 色: オレンジ（`#FF8C00`）
- CSS疑似要素（`::after`）で実装し、セルに `data-bookmarked` 属性を付与して制御する
- マークはスクロールやセル再描画時にも維持される
- ブックマーク削除時にマークが即座に消える

### サイドバー BOOKMARKS パネル

- アクティビティバーにブックマークアイコンを追加する
- パネル内にブックマーク一覧をリスト表示する:
  - テーブル名（グループヘッダー）
  - 各ブックマーク: `列名: ラベル（主キー値）`
- 各アイテムにホバーで削除ボタン（×）を表示する
- ドラッグ&ドロップによる並び替えに対応する（将来拡張、初期実装では不要）

## 期待される動作

### ブックマークの追加とジャンプ

1. `item` テーブルの `id=3` の `name` 列セル（値: "ポーション"）を選択する
2. `Ctrl+D` を押す
3. セルの右上にオレンジの三角マークが表示される
4. `bookmarks.json` に即座に保存される
5. 別のテーブルで作業する
6. サイドバーの BOOKMARKS パネルを開く
7. `item` グループ内の `name: ポーション (3)` をクリックする
8. `item` テーブルが開き、`id=3` の行の `name` 列セルにジャンプ＋選択される

### ブックマークの削除

1. ブックマーク済みセルを選択する
2. `Ctrl+D` を押す（トグルで削除）
3. セルの右上のオレンジマークが消える
4. `bookmarks.json` から即座に削除される
5. サイドバーの BOOKMARKS パネルからも消える

### コンテキストメニューからの操作

1. セルを右クリックする
2. ブックマーク未登録の場合: 「ブックマークに追加」が表示される
3. ブックマーク登録済みの場合: 「ブックマークを削除」が表示される

## 保存ファイル形式

```json
[
  {
    "tableName": "item",
    "rowKey": "3",
    "columnName": "name",
    "label": "ポーション",
    "createdAt": "2026-03-28T10:30:00.000Z"
  },
  {
    "tableName": "enemy",
    "rowKey": "5",
    "columnName": "name",
    "label": "ドラゴン",
    "createdAt": "2026-03-28T11:00:00.000Z"
  }
]
```
