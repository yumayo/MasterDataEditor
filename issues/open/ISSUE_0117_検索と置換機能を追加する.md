# ISSUE_0117 検索と置換機能を追加する

## 概要

Ctrl+H で起動する「検索と置換」機能を追加する。現在の全文検索パネル（SEARCHパネル）は検索のみ対応しているが、マッチしたセルの値を一括または個別に置換する手段がない。Excel の Ctrl+H や VSCode の検索置換と同等の操作感を実現する。

## 背景

マスターデータの運用では「アイテム名の接頭辞を一括変更」「廃止されたIDを新IDに差し替え」「typoの一括修正」といった置換操作が頻繁に発生する。現状ではCSVを外部エディタで開いて置換するか、1セルずつ手動修正するしかなく、非エンジニアのゲームプランナーにとって大きな作業負担となっている。

## 要件

### 起動方法

- Ctrl+H で検索置換モードを起動する
- 既存のSEARCHパネルに置換UIを統合する（検索入力欄の下に置換入力欄を追加表示する）
- Ctrl+F は従来通り検索のみ（置換入力欄は非表示）

### 置換UI

- 検索入力欄の直下に置換入力欄を配置する
- 置換入力欄の右側に以下のボタンを表示する:
  - **置換**（1件置換）: 現在ハイライトされているマッチを置換し、次のマッチに移動する
  - **すべて置換**: 全マッチを一括置換する
- 既存の検索オプション（大文字小文字区別 / 単語単位 / 正規表現）はそのまま置換にも適用する

### 検索結果のハイライトとナビゲーション

- マッチしたセルを検索結果一覧に表示する（既存動作）
- 現在の注目マッチをハイライト表示する（背景色で区別）
- Enter / Shift+Enter または上下ボタンで次/前のマッチに移動する
- マッチ移動時に該当テーブルのタブを開き、該当セルにスクロール＋選択する

### 個別置換

- 「置換」ボタンクリックで現在の注目マッチ1件を置換する
- 置換後、次のマッチに自動移動する
- 置換操作は Command パターンで実装し、Undo/Redo に対応する

### 一括置換

- 「すべて置換」ボタンクリックで全マッチを一括置換する
- 置換件数をステータスバーまたは通知トーストで表示する（例: 「23件を置換しました」）
- 一括置換も単一の Command として Undo/Redo に対応する（1回の Undo で全件戻る）

### 正規表現置換

- 正規表現オプションON時、置換文字列でキャプチャグループ参照（$1, $2 等）を使用可能にする
- 例: 検索 `item_(\d+)` → 置換 `ITEM_$1` で `item_001` が `ITEM_001` に変わる

### スコープ制御

- **アクティブテーブル**: 現在のタブのテーブルのみを対象にする
- **全テーブル**: 開いている全テーブルを横断して置換する
- スコープ切替はトグルボタンまたはドロップダウンで行う

### 安全性

- 置換プレビュー: 「すべて置換」実行前に置換件数を表示する
- PK列の置換は参照整合性を壊す可能性があるため、警告を表示する
- 置換後にバリデーションを自動実行し、FK参照切れ等があれば即座にエラー表示する

## 期待される動作

1. Ctrl+H を押すとSEARCHパネルが開き、置換入力欄が表示される
2. 検索欄に文字列を入力するとマッチ結果が一覧表示される
3. Enter で次のマッチに移動し、該当セルがハイライトされる
4. 置換欄に置換後の文字列を入力する
5. 「置換」ボタンで1件置換 → 次のマッチに自動移動
6. 「すべて置換」ボタンで全マッチを一括置換 → 件数を通知
7. Ctrl+Z で置換を取り消せる
