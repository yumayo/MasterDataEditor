# ISSUE_0114 ブックマーク機能を追加する

## 概要

特定のセル（テーブル + 主キー）をブックマークとして保存し、ワンクリックで該当セルにジャンプできる機能を追加する。アクティビティバーにブックマーク専用のアイコンを配置し、サイドバーパネルとして全文検索パネルと同様のUIで一覧表示する。

## 背景

大量のマスターデータを編集する際、頻繁に参照・編集するレコードが決まっていることが多い。現状ではそのたびに全文検索やエクスプローラーからテーブルを開き、目的の行までスクロールする必要がある。ブックマーク機能があれば、よく使うセルに即座にジャンプでき、編集効率が大幅に向上する。

## 要件

### アクティビティバー

- 新しいアクティビティバー項目 `bookmarks` を追加する
- ブックマークアイコン（旗 or しおり形状のSVG）をアクティビティバーに表示する
- 表示位置は SEARCH と SOURCE CONTROL の間

### ブックマークパネル（サイドバー）

- 全文検索パネルと同様のレイアウトでブックマーク一覧を表示する
- 各ブックマークエントリにはテーブル名・主キー値・表示列の値を表示する
- エントリクリックで該当テーブルをタブで開き、該当行のセルにジャンプ（選択状態にする）
- ブックマーク削除ボタン（各エントリの右端に x アイコン）

### ブックマークの追加操作

- セルを右クリック → コンテキストメニューに「ブックマークに追加」を表示する
- 既にブックマーク済みの行では「ブックマークを解除」を表示する

### データ構造

- ブックマーク1件 = テーブル名 + 主キー値
- ブックマーク一覧はメモリ上で保持する（永続化は将来課題）

## 期待される動作

1. ユーザーがセルを右クリックし「ブックマークに追加」を選択する
2. アクティビティバーのブックマークアイコンをクリックしてパネルを開く
3. 登録したブックマークが一覧表示される（テーブル名でグルーピング）
4. エントリをクリックすると該当テーブルがタブで開かれ、該当行にスクロール＋セル選択される
5. エントリの x ボタンで個別削除できる
