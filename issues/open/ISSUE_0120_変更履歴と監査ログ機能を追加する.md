# ISSUE_0120 変更履歴・監査ログ機能を追加する

## 概要

「誰が・いつ・どのセルを・どう変えたか」をGitの履歴から抽出し、テーブル上で閲覧できる機能を追加する。セル単位の変更履歴（git blame相当）と、テーブル全体の変更タイムライン（git log相当）の2つの視点を提供する。

## 背景

マスターデータは複数のゲームプランナーやエンジニアが共同で編集する。現状、誰がいつ何を変更したかを確認するにはGit CLIやGitHub上でCSVの差分を読む必要があり、非エンジニアにとって敷居が高い。特に以下のケースで問題になる:

- 不正な値がいつ混入したか特定したい（デバッグ時）
- 特定の行を最後に編集した人に確認を取りたい
- リリース前にどの行が変更されたか一覧で確認したい
- 意図しない変更が混入していないかレビューしたい

## 要件

### 1. セル単位の変更履歴（git blame ビュー）

#### 表示方法
- 列ヘッダーまたはコンテキストメニューから「変更履歴を表示」を選択する
- テーブルの各行の左端（行ヘッダーの隣）に blame 情報列を追加表示する
- blame 情報列には最終変更者名・変更日時を表示する
- blame 情報列はトグルで表示/非表示を切り替えられる

#### blame 情報の内容
- **変更者名**: git commit の author 名
- **変更日時**: コミット日時（相対表示: 「3日前」「2週間前」等）
- **コミットメッセージ**: ツールチップでホバー時に表示

#### セル単位の詳細履歴
- セルを右クリック → 「このセルの変更履歴」を選択する
- ポップアップまたはパネルに該当セルの変更履歴を時系列で表示する:
  - 変更日時
  - 変更者名
  - 変更前の値 → 変更後の値
  - コミットメッセージ

### 2. テーブル変更タイムライン（git log ビュー）

#### アクティビティバー
- 新しいアクティビティバー項目 `history` を追加する
- 時計アイコンをアクティビティバーに表示する

#### タイムラインパネル
- サイドバーパネルとしてテーブルの変更履歴を時系列で表示する
- 現在アクティブなタブのテーブルに絞った履歴を表示する
- 各エントリに以下を表示する:
  - コミットメッセージ
  - 変更者名
  - 変更日時（相対表示）
  - 変更行数（追加・削除・変更の件数）
- エントリをクリックすると、そのコミットでの差分を差分タブで表示する

### 3. バックエンドAPI

- `git_blame`: テーブルファイルの行ごとのblame情報を取得する
- `git_log`: テーブルファイルのコミット履歴を取得する（件数制限付き）
- `git_show_at_commit`: 特定コミットでのテーブルファイルの内容を取得する
- `git_diff_commits`: 2つのコミット間のテーブルファイルの差分を取得する

### 4. 行単位の変更ハイライト

- blame 情報に基づき、直近N日以内に変更された行を薄い背景色でハイライトする
- ハイライトの閾値（N日）は設定で変更可能にする
- 同一コミットで変更された行は同じ色でグルーピングする

### 5. 変更フィルタリング

- タイムラインパネルで変更者名でフィルタリングできる
- 日付範囲でフィルタリングできる（例: 「直近1週間」「今月」「カスタム範囲」）

## 期待される動作

1. テーブルを開き、コンテキストメニューから「変更履歴を表示」を選択する
2. 各行の左端に最終変更者名と日時が表示される
3. セルを右クリックして「このセルの変更履歴」を選択すると、そのセルの値の変遷が表示される
4. アクティビティバーのタイムラインアイコンをクリックすると、テーブルのコミット履歴が一覧表示される
5. タイムラインのエントリをクリックすると、そのコミットでの差分が差分タブで表示される
