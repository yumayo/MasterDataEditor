# ISSUE_0123 任意コミット間のデータバージョン比較を追加する

## 概要

任意の2つのGitコミットを指定して、テーブルデータの差分を既存の差分ビュー（DiffTab）で表示できる機能を追加する。現状の差分ビューはHEAD版と作業ツリー版の比較のみだが、過去の任意バージョン間での比較にも対応する。

## 背景

マスターデータの運用では以下の場面で過去バージョン間の比較が必要になる:

- **リリース前レビュー**: 前回リリースタグから現在までの全変更を一覧で確認したい
- **不具合調査**: 「先週まで正しかったデータがいつ壊れたか」を特定するため、特定コミット間の差分を確認したい
- **ブランチ比較**: featureブランチとmainブランチのデータ差分を確認したい
- **ロールバック判断**: 特定コミットに戻すべきか判断するため、そのコミット時点のデータを確認したい

現状はこれらをGit CLIで `git diff <commit1> <commit2> -- data/table.csv` として確認するしかなく、CSVの生差分は行の対応関係が分かりにくい。既存のDiffTabはPKベースで行を対応付けて表示するため、この仕組みを任意コミット間に拡張すれば格段に見やすくなる。

## 要件

### コミット選択UI

#### 起動方法
- テーブルタブのコンテキストメニューに「バージョン比較...」を追加する
- クリックでコミット選択ダイアログを表示する

#### コミット選択ダイアログ
- 左ペイン（比較元）と右ペイン（比較先）それぞれにコミットを選択するUIを提供する
- 各ペインにはコミット一覧をドロップダウンまたはリストで表示する
- コミット一覧の各エントリに以下を表示する:
  - コミットハッシュ（短縮7桁）
  - コミットメッセージ（1行目）
  - コミット日時（相対表示）
  - 変更者名
- プリセット選択肢:
  - 「HEAD（最新コミット）」
  - 「作業ツリー（未コミット変更を含む現在の状態）」
  - 「N個前のコミット」（HEAD~1, HEAD~2, ...）
- コミット一覧はそのテーブルファイルに関連するコミットのみ表示する（`git log -- data/{テーブル名}.csv`）
- 「比較」ボタンで差分タブを開く

### 差分表示

#### 既存DiffTabの拡張
- 現状のDiffTabはHEAD版 vs 作業ツリーの固定比較だが、任意の2つのデータソースを受け取れるように拡張する
- 左ペイン: 比較元コミットのテーブルデータ
- 右ペイン: 比較先コミットのテーブルデータ
- 両ペインとも読み取り専用とする（過去コミットのデータは編集不可）
- ただし比較先が「作業ツリー」の場合、右ペインは編集可能とする（既存動作と同じ）

#### タブ表示
- タブ名: `{テーブル名} (abc1234 ↔ def5678)` 形式でコミットハッシュを表示する
- 比較先が作業ツリーの場合: `{テーブル名} (abc1234 ↔ 作業ツリー)`
- 比較先がHEADの場合: `{テーブル名} (abc1234 ↔ HEAD)`

#### ラベル表示
- 左ペイン上部ラベル: コミットハッシュ + コミットメッセージ + 日時
- 右ペイン上部ラベル: 同上（作業ツリーの場合は「作業ツリー（未保存の変更を含む）」）

### バックエンドAPI

- `git_log_file`: 特定ファイルのコミット履歴を取得する（コミットハッシュ・メッセージ・日時・変更者名の配列）
- `git_show_at_commit`: 特定コミットでの特定ファイルの内容を取得する（`git show <commit>:<path>` 相当）

### 差分の統計情報

- 差分タブのヘッダー領域に統計サマリを表示する:
  - 追加行数（新規PK）
  - 削除行数（消滅PK）
  - 変更行数（同一PKで値が異なる）
  - 変更セル数

## 期待される動作

1. テーブルタブを右クリックし「バージョン比較...」を選択する
2. コミット選択ダイアログが開き、該当テーブルに関連するコミット一覧が表示される
3. 左ペインに「3日前のコミット（abc1234）」、右ペインに「HEAD」を選択する
4. 「比較」をクリックすると、差分タブが開く
5. 左ペインに3日前のデータ、右ペインに最新データが表示され、変更セルがハイライトされる
6. タブ名に `enemy (abc1234 ↔ HEAD)` と表示される
7. ヘッダーに「追加: 3行、削除: 1行、変更: 5行（12セル）」と統計が表示される
