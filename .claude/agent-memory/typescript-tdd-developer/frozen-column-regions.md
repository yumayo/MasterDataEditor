# 固定列の分離描画と操作座標

- 中央の元セルは viewport 幅だけでなく中央列の総幅でもクリップする。右固定列を複製して中央から除外しないと、短い表の余白へ二重描画される。
- 固定領域の幅を制限する場合は、隠れた列へ矢印キー・Shiftホイールで到達できる内部水平位置も必要。左側は行番号/blameを動かさず、データ列と罫線・選択枠を同じ範囲でクリップする。
- querySelector のカンマ区切りはセレクター順の優先指定ではなくDOM順。ドラッグ境界には表示用の固定ヘッダーを個別取得し、本文内の非表示sourceヘッダーを選ばない。
- EditorTableHandler.hide の focusWithoutScrolling は旧位置へのrAF復元を予約する。Selection.scrollCellIntoView は ensureRowVisible が変更した縦位置も最終補正に含めないと、固定行でEnter後に次行が画面外へ戻る。
- 編集後の検証は2フレーム経過後の選択値だけでなく、次セルの可視・focusedクラス・選択枠まで確認する。
