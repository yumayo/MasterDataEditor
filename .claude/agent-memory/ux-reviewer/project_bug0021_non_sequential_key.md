BUG_0021（スキーマのkeyが非連番のときソート・差分ビューがずれる）の修正がUXレビュー評価Aで承認された（2026-03-16）。

**Why:** DOM列インデックスをそのままCSV列インデックスとして使っていた箇所が2か所あり、非連番keyスキーマでソートが誤列参照・差分ビューがクラッシュしていた。

**How to apply:** 今後ソート軸や差分比較ロジックを追加する際は「DOM列インデックスとCSV列インデックスの変換が正しく行われているか」を必ず確認する。非連番keyスキーマでのテストケースを追加すること（操作パスの網羅漏れパターン#2の典型例）。

## 修正確認済み事項
- ソート: `data-store-index` が attack昇順(10<50<80)に正しく並び替わる（DOM列1=CSV列3の変換OK）
- 差分ビュー: CSV列5(recover_hp)→DOM列3への変換が正しく行われ `diff-cell-deleted/added` が正確
- PK バッジが差分ビュー左右ペイン両方に正しく引き継がれている
- `editor-right-slot` が `display:none` で非表示制御されている（差分タブでRelationsPanelは不要）

## 残課題（未対応）
- 差分ビュー左ペイン（HEAD版）に `aria-readonly="true"` などの読み取り専用マークアップがない（前回レビューから継続）
- 差分ビューの行レベルに `data-diff-kind="modified"` などの属性がなく行単位のアクセシビリティ強調が困難
- `editor-right-slot` 内のRelationsPanelプレースホルダーが「行を選択してください」のまま（差分タブ文脈では不適切）
